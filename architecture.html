Explore at your own scale

Drag to orbit, right-drag to pan, scroll or pinch to zoom. Select a component, then double-click or press Enter to open it. The component index provides the same navigation without using the canvas.

Semantic zoom reveals actual child components as the selected region grows. Zoom farther in to enter it; zoom well out to return to its parent. Use the explicit navigation buttons whenever you prefer.

Geometry is schematic. Color identifies an operation family. Box sizes and distances do not measure parameter count, feature dimensionality, or execution time. Solid arrows show declared dependencies; dashed lines show shared parameter identity.

Numbers need evidence. Structural packages provide tensor shapes and coordinates. Missing values remain unavailable. The arithmetic workbench uses a separate computed miniature. Imported files are processed in this browser and are not uploaded.

Import: ModelIR 1.0 JSON or gzip, or an optional local safetensors file for a tensor catalog. Generate new architecture packages with the separate Python extractor. Arbitrary model configurations need an adapter.
